# Saldo

App web de controlo financeiro pessoal: receitas, despesas, saldo, orçamentos mensais e gastos por categoria.

Stack: React + Vite + TypeScript, Tailwind CSS + shadcn/ui, Supabase.

## Comandos

| Comando                | O que faz                            |
| ---------------------- | ------------------------------------ |
| `npm run dev`          | Servidor de desenvolvimento          |
| `npm run build`        | Verifica tipos e gera a build        |
| `npm run lint`         | Analisa o código (oxlint)            |
| `npm test`             | Corre os testes (Vitest)             |
| `npm run format`       | Formata o código (Prettier)          |
| `npm run format:check` | Confirma que o código está formatado |
